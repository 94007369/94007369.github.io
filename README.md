# Bohong (Lucia) Liu — Academic Website

English academic portfolio at https://94007369.github.io, built with Jekyll and hosted on GitHub Pages. The repository retains its Academic Pages foundation; the public site uses a compact custom layout without JavaScript or third-party tracking.

## Update content

- `_pages/about.md`: biography and academic background
- `_pages/research.md`: research projects and assistant experience
- `_pages/projects.md`: methods and public project materials
- `_pages/cv.md`: web CV
- `assets/CV-BohongLiu.pdf`: downloadable CV
- `_pages/contact.md`: verified contact information
- `_data/navigation.yml`: navigation
- `_layouts/academic.html` and `assets/css/academic.css`: layout and styling

Keep the web and PDF CV synchronized. Add links to code or papers only after the actual materials are available. Stanford Summer Session and UCLA exchange are non-degree experiences. Research assistant roles have no dates listed because dates were not supplied.

## Deployment

GitHub Pages builds the `master` branch. Check the repository Actions page after a content update, then verify the five main routes and the CV/report download links. Unused sample collections are excluded from the build.
